Map shows location of rain gauges and rainfall amounts for the selected day. Note that by default only gauges that have data for the selecte date are shown, but you can show location of all stations using the toggle. Some sites report data only when it rains. When it does not rain - they report nothing. When we receive no data for a given day, We do not know, unfortunately, whether this means that there was no rain, or perhaps that there was no measurement done on that day. It is possible that there was no rainfall over gagues with no data, but it is not 100% sure.
