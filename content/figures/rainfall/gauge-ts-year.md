This chart illustrates total rainfall measured over a year. It uses a hydrological year that starts in October and finishes in September. Note that bars have two colours that signify the robustness of data. It is only natural that some measurements are missing. Observers might have not recorded data, or rain gauge was broken etc. Additionally, often, observers report data only when it rains, and do not report 0s when it does'nt. This creates a bit of a problem because if there is no data reported, we do not know if this is because there was no rain, or perhaps rain wasn't measured. In many cases we make an educated guess that missing data are simply 0s, but we cannot always do that. This way or nother - we count how many days have missing values and if there is more than 10% of such days (i.e. more than 36 days in a year), we flag the year's total as not-robust
